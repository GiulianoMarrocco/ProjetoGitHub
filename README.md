## 🎯 Objetivo
 
Este projeto foi desenvolvido como exercício prático para aplicar conceitos de **CSS intermediário**, incluindo:
 
- Estruturação semântica com HTML
- Layouts com Flexbox/Grid
- Estilização avançada de componentes
- Organização e responsividade de página
